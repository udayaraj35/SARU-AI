# Exact scheduled WhatsApp messages

Configure Social accounts with your WhatsApp Business phone ID, access token and supported Meta Graph API version. The AI provider key alone does not grant WhatsApp account access. No credentials are included in the installer; each Windows user supplies their own.

Example: schedule whatsapp in 10 minutes to +9779800000000: Hello

This exact command authorizes one message to the specified recipient at that relative time. show scheduled messages lists local status; cancel scheduled message 1 cancels before an attempt begins. No message has been sent during development.

The queue is persistent and message content is encrypted for the Windows user. The PC must be awake and SARU running. Work more than ten minutes late expires; changed accounts/tokens are blocked. A claimed job is not automatically retried after an interruption, network uncertainty or error. Check the real account before any manual retry. Accepted means Meta accepted the API request, not verified delivery.

Personal WhatsApp Web can open a selected chat/draft in SARU Browser. Reliable unattended personal-account sending and arbitrary automatic replies are not implemented; SARU does not silently press Send on an unverified chat.
