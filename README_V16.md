# SARU AI v16 — Round photo desktop icon

This version preserves the v15 source, settings, MYRA guides and features. It replaces the old S desktop shortcut icon with a round SARU portrait (`saru.ico`) and includes `saru_animated_preview.gif` as an animated visual preview. **Windows .ico desktop shortcuts cannot animate**; the GIF is not an animated desktop shortcut.

## Upgrade
Close SARU, extract this ZIP, run `install_and_run.bat`, choose the existing install folder, and select Desktop shortcut. To refresh an existing shortcut after installation, use Settings > Desktop shortcut / start with Windows, or run `refresh_desktop_icon.bat` from the installed directory. Windows icon caching may require signing out/in.

The icon is fixed in this release; selecting a new avatar in Appearance does not automatically regenerate the shortcut icon. This build has not been tested on a Windows PC; it is a source ZIP, not a signed EXE installer. Windows 10/11 are targeted. Windows 8 compatibility is not guaranteed. Do not run downloaded updates without verifying publisher and backup.
