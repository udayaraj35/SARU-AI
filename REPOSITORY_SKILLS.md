# SARU 2.5 repositories, profiles and desktop actions

Owner and Creator profiles are independent. Owner fields include name, email, phone, social links, occupation, address, country, birthday, biography, additional information and a copied photo. Creator defaults are Udaya Raj Khanal's supplied contact details and portrait, with https://www.youtube.com/@udayaraj3 . Owner information remains local and is not automatically placed in AI context. Brand buttons use bundled Simple Icons assets; see BRAND_ASSETS.md.

**Repository Skills** in the sidebar and Settings imports public GitHub reference/prompt content at a resolved commit. A future request such as `add repo https://github.com/owner/repository` opens the center and fetches a pinned preview. Review its source, README, license and manifest, then install its text. Imported prompts are searchable and only the explicitly selected reference is included in chat context. Reconnect voice after changing the selection. This does not make arbitrary repository code into executable desktop tools.

The supplied `f/prompts.chat` snapshot includes its CSV dataset plus README, license and SKILL.md references. Its prompt data is CC0; source code is separately licensed. `harry0703/MoneyPrinterTurbo` is also available as a dedicated video-engine adapter. Generic repository installers, scripts and remote MCP servers are not silently executed. Another executable engine needs an explicit adapter and dependency setup.

MoneyPrinterTurbo is pinned at `33dde166da7f75287ea727c10e37243f03d167c8`, with a private Python environment under the local SARU data directory's `mpt-env` folder. This keeps its Google SDK and multimedia dependencies separate from SARU Live Voice and avoids Windows long-path failures. The environment is dependency separation, not a security sandbox. The adapter runs only on 127.0.0.1:8088 with a generated API token; it supports video generation and task-status queries through the repository's actual API. Configure its LLM, stock-media and voice settings in its own config.toml before requesting a production video. Charges and provider account requirements depend on those settings. No publication is triggered by generation.

**Open App** now catalogs Start Menu shortcuts, Windows registered/Store apps, registry App Paths and explicitly chosen portable EXEs. Name matching does not evaluate shell arguments. Missing or ambiguous apps open the catalog rather than a false permissions error. PC Control provides local preview and reviewed clicks, Unicode text, scrolling and shortcuts. Its new AI planner receives a screenshot only after approval, returns one validated action, and requires a second review before input. Each step retains fresh-image, target-patch and foreground-window checks. Capture again to verify and plan another step. Protected/elevated Windows UI and unsupported codecs/providers can still require owner intervention; universal unattended operation is not claimed.
